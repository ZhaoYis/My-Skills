## Why

当前贪吃蛇游戏只有一套固定的深蓝灰配色方案。所有颜色（蛇身翠绿渐变、红色食物、暗色背景）都硬编码在 CSS 变量和 Canvas 绘制代码中。用户无法根据个人喜好切换视觉风格。引入皮肤系统可以：

- 提升用户的视觉新鲜感和个性化体验
- 增加游戏的重玩吸引力
- 为后续皮肤扩展（社区皮肤、节日限定等）奠定架构基础

## What Changes

- **新增皮肤定义模块**：4 套纯色皮肤（经典、复古、午夜、暖橙），每套包含 CSS 层和 Canvas 层的完整配色
- **新增皮肤切换 UI**：游戏界面中一排圆形色块按钮，点击或按 `T` 键即可切换
- **皮肤持久化**：用户选择的皮肤保存到 localStorage，下次自动加载
- **重构现有绘制代码**：将 `draw()` 和 `spawnParticles()` 中所有硬编码颜色改为从当前皮肤对象读取
- **CSS 变量动态化**：移除 `:root` 中固定的颜色变量，改为 JS 动态注入

## Capabilities

### New Capabilities

- `skin-system`: 皮肤定义注册表 + 运行时切换 + localStorage 持久化，覆盖 DOM (CSS 变量) 和 Canvas 两个渲染层

### Modified Capabilities

- 无（现有功能行为不变，仅视觉呈现可配置）

## Impact

- **修改文件**：`index.html`（所有改动集中在一个文件中）
- **DOM 新增**：一行 4 个圆形色块按钮 + hover tooltip
- **键盘新增**：`T` 键绑定（循环切换皮肤）
- **Canvas 重绘**：`draw()` 函数中约 15 处硬编码颜色替换为动态读取，逻辑不变
- **兼容性**：桌面端（T 键 + 点击）、移动端（触摸点击），所有现代浏览器均支持
