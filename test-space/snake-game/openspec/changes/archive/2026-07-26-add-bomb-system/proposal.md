# Proposal: 炸弹系统

## Why

当前游戏在经典模式和计时模式下缺乏动态环境威胁——所有危险都是可预测的（墙壁、蛇身）。炸弹系统引入不可预测的爆炸性障碍物，在两种模式中创造"风险与机遇并存"的策略深度，同时将特殊道具系统扩展到经典模式以平衡新增的难度。

## What Changes

- **新增炸弹系统**：两种炸弹类型（休眠/不稳定）以随机间隔在棋盘空单元格上生成，上限 6 颗
- **休眠炸弹 (70%)**：触碰扣 2-3 段身体，炸弹消失；不会自爆
- **不稳定炸弹 (30%)**：触碰立即引爆；3-8 秒后随机自爆；外观带火花粒子警示
- **爆炸机制**：3×3 范围冲击波，蛇头命中死亡，蛇身命中截断，食物被摧毁重生，其他炸弹被波及则连锁引爆
- **连锁引爆**：连续引爆的炸弹带来递增分数倍率（×1 → ×2 → ×3 ...）
- **护盾与炸弹交互**：护盾可挡一次爆炸死亡（消耗护盾），但不防休眠炸弹触碰扣段
- **特殊道具扩展到经典模式**：金苹果 (12%)、闪电 (5%)、护盾 (3%) 现在也在经典模式中生成
- **新增皮肤参数**：每套皮肤增加炸弹休眠色、炸弹不稳定色、爆炸光效色等 Canvas 绘制参数

## Capabilities

### New Capabilities

- `bomb-system`: 炸弹的生成、类型区分、爆炸、连锁反应、渲染、与道具交互的完整系统

### Modified Capabilities

- `timed-mode`: 特殊道具（金苹果/闪电/护盾）从仅计时模式扩展到经典模式；护盾增加对爆炸伤害的保护逻辑
- `skin-system`: 每套皮肤新增炸弹和爆炸相关的 Canvas 绘制颜色参数

## Impact

- **代码**：`index.html` — 新增 `BOMB_TYPES` 常量、`bombs[]`/`explosions[]` 状态、`spawnBomb()`/`triggerExplosion()`/`drawBombs()`/`drawExplosions()` 函数；修改 `initGame()`/`update()`/`draw()`/`gameOver()`；经典模式启用 `rollItemType()` 特殊道具生成
- **皮肤系统**：`SKINS` 注册表中每套皮肤新增约 8-10 个 Canvas 颜色参数
- **UI/UX**：Canvas 画布上新增炸弹渲染和爆炸动画（~400ms），无额外 DOM 元素；爆炸时 Canvas wrapper 触发震屏动画
- **浏览器兼容性**：`CanvasRenderingContext2D.roundRect()` 已在蛇身绘制中使用，炸弹渲染沿用此 API（Chrome 99+, Firefox 112+, Safari 15.4+）
- **性能**：每帧额外渲染 ≤6 颗炸弹 + 少量爆炸动画粒子，对 60fps 无影响
