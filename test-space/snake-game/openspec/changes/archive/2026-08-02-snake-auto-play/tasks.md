## 3. AI 决策引擎实现

- [x] 3.1 实现 `getAIDirection()` 函数 —— 候选方向筛选
  - 完成标准：遍历上下左右，排除 180° 反向、撞墙、撞自身的方向

- [x] 3.2 实现 `getAIDirection()` 函数 —— 安全检查（炸弹避让）
  - 完成标准：检查候选方向是否在不稳定炸弹上或爆炸范围内；有安全方向时只保留安全方向

- [x] 3.3 实现 `getAIDirection()` 函数 —— 评分系统
  - 完成标准：食物引力 +5、墙壁安全 +3、炸弹规避 +4、空间评估 +2（≥30 格）/-3（<10 格）、道具吸引 +3
  - **手动测试**：开启挂机 → 观察蛇优先朝向食物移动 → 放置炸弹 → 观察蛇避开 → 生成护盾/闪电道具 → 观察蛇积极靠近

- [x] 3.4 实现 `floodFillCount()` 函数 —— 简易洪水填充空间评估
  - 完成标准：从指定位置开始 BFS，深度限制 50 步，返回可达格子数量
  - **手动测试**：蛇身处空旷区域 → 返回 ≥50；蛇身处窄通道 → 返回值明显小于蛇身处空旷区域

- [x] 3.5 实现方向保持策略（80% 概率保持当前方向）
  - 完成标准：当前方向在安全候选方向中时 80% 概率返回当前方向
  - **手动测试**：观察蛇在无威胁时大多数帧保持直行，偶尔转弯
