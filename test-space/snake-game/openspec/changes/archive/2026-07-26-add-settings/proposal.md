## Why

当前游戏的配置项（皮肤、音效、昵称、模式）分散在底部栏、开始覆盖层、排行榜面板等不同位置，缺少统一入口。此外，游戏没有难度梯度——新手和高手面对相同的速度和炸弹频率，无法根据自身水平调整体验。需要一个集中式设置面板来整合配置并提供难度选择。

## What Changes

- 底部栏新增 ⚙️ 齿轮图标，点击打开设置面板（Modal）
- 设置面板按类型分区：游戏、外观、音效、玩家
- **难度预设**：简单（纯经典，无炸弹）、普通（当前默认参数）、困难（更快的速度和更激进的炸弹）
- 皮肤选择从底部栏独立 swatch 改为设置面板内选择器
- 新增网格线显示/隐藏开关
- 音效开关（替代现有 🔇 按钮）
- 玩家昵称修改入口
- 重置设置按钮 + 导出游戏数据按钮
- 持久化统一到单一 `snake-settings` key，迁移旧数据

## Capabilities

### New Capabilities
- `game-settings`: 集中式设置面板 UI（⚙️ 入口图标、Modal 弹窗、分区布局、统一持久化）
- `difficulty-presets`: 三档难度预设（简单/普通/困难），控制游戏速度和炸弹行为

### Modified Capabilities
- `bomb-system`: 炸弹行为与难度联动——简单模式完全禁用炸弹，困难模式增加炸弹频率和降低休眠概率
- `skin-system`: 皮肤选择 UI 从底部栏 swatch 行移入设置面板（渲染系统不变）

## Impact

- 受影响文件：`index.html`（新增设置面板 HTML/CSS/JS）
- 新增 localStorage key：`snake-settings`（一次性迁移旧 key 后清除）
- 底部栏 UI 调整：移除皮肤 swatch 行，替换为简洁的 ⚙️ 入口 + 帮助按钮
- 难度变更为运行时生效——选择后立即更新 game loop 参数
- 兼容性：所有现代浏览器（localStorage 依赖）
