# 原型交付走查清单

## 主流程

- [ ] 从第一步到最终结果，底栏按钮每步正确
- [ ] 长任务进行中底栏隐藏，结束后恢复
- [ ] 成功 / 失败 / 超时 底栏分支正确（非成功态不出现成功 CTA）
- [ ] 步骤条文案与当前界面一致，高度可读
- [ ] 已完成步骤可回跳；进行中不可乱跳

## 异步与等待

- [ ] 阶段列表与进度/倒计时同步推进
- [ ] 倒计时标注为「参考」而非精确承诺
- [ ] 异步/可离开提示表述清楚
- [ ] 未实现的操作按钮已移除

## 弹窗

- [ ] 打开/关闭不破坏页面滚动与标注位置
- [ ] Loading 在弹窗内，footer 仍在且主按钮 disabled
- [ ] 失败可重试；取消行为符合预期
- [ ] 多文件（若有）：追加、删除、上限、格式提示
- [ ] Hero 与 dialog 顶角圆角一致

## 标注（若启用）

- [ ] 每条编号在界面上可见且位置不重叠、不被裁剪
- [ ] 弹窗打开时仅弹窗标注显示
- [ ] 右侧面板分组与当前步骤高亮正确
- [ ] 点击面板项可定位并闪动徽章
- [ ] **业务文案**无技术词、与按钮文案一致、选填/必选准确
- [ ] 原型限制已注明（未做校验、演示切换等）

## 演示与交付说明

- [ ] URL 参数可演示失败/超时/成功分支
- [ ] 交付时附：操作顺序 + 演示参数 + 未实现清单

## 代码质量（内部）

- [ ] 无大块死代码/未使用 CSS
- [ ] 状态变量与 UI 更新路径清晰
- [ ] 视觉与改前一致（抛光未改风格）

## 视觉美化（若执行 Phase 6B）

- [ ] 美化前已向用户展示 3～4 套风格并已确认
- [ ] 遵循 ui-ux-pro-max（对比度、focus、动效、图标规范）
- [ ] CSS token 统一，无零散硬编码色值
- [ ] 主流程交互与 Phase 6B 前一致
