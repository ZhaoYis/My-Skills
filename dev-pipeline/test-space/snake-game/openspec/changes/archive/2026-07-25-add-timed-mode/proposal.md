## Why

当前贪吃蛇只有经典无限模式——蛇不断移动吃食物，碰到墙壁或自身游戏结束。玩家需要一个更有时间压力的玩法变体，让游戏节奏更紧张、决策更有紧迫感。计时模式（时间抢夺）引入倒计时机制，玩家必须在时间耗尽前持续吃食物维持计时器，同时特殊物品增加策略深度。

## What Changes

- **新增计时模式**：初始 60 秒倒计时，吃食物 +5 秒（上限 90 秒），时间归零游戏结束
- **新增模式选择 UI**：开始覆盖层中展示经典 / 计时两张模式卡片，点击或键盘切换
- **新增特殊物品系统**（计时模式专属）：金苹果（+20 分 +10 秒）、闪电（速度减半 3 秒）、护盾（免死一次）
- **新增计时器 UI**：Header 新增"剩余时间"卡片，颜色随剩余时间变化
- **分数存储隔离**：经典模式和计时模式各自独立存储最高分
- **区分游戏结束类型**：撞墙/撞自己显示"游戏结束"，时间耗尽显示"时间到"

## Impact

- 单文件项目 `index.html`（约 1165 行），所有修改集中在此文件
- CSS 变量体系：新增计时器颜色状态变量（绿/黄/红脉冲）

- localStorage：新增 `snake-best-score-timed` 键，皮肤选择仍共用 `snake-skin`
- Canvas 渲染：新增特殊物品绘制、护盾/闪电视觉效果、10 秒警告脉冲动画
