## Context

当前项目为单文件 HTML 贪吃蛇游戏（`index.html`，约 1165 行），采用 IIFE 模式组织 JS 代码，CSS 变量 + 皮肤注册表实现多皮肤切换。游戏循环基于 `requestAnimationFrame` + accumulator 模式，每秒约 9 tick（110ms/tick）。

本次新增计时模式，保留经典模式，两者通过开始覆盖层切换。皮肤系统、Canvas 渲染管线、输入处理逻辑均复用。

## Goals / Non-Goals

**Goals:**
- 实现计时模式完整玩法（倒计时、时间抢夺、特殊物品）
- 模式选择 UI 直观且默认经典模式（向后兼容）
- 特殊物品有明确视觉区分和效果反馈
- 计时模式下暂停时计时器同步暂停
- 经典/计时最高分独立存储

**Non-Goals:**
- 不新增皮肤（复用现有 4 套）
- 不修改经典模式的任何行为
- 不引入多人对战、排行榜等社交功能
- 不引入音效

## Decisions

### 1. 单文件内通过 `gameMode` 标志区分模式

**决策**：不拆分为多个 HTML 或 JS 文件，在现有 `index.html` 中通过 `gameMode: 'classic' | 'timed'` 状态字段控制逻辑分支。

**理由**：项目已是单文件结构，改动量可控；避免引入构建工具或模块加载。

### 2. 计时器使用 game loop 内 accumulator 而非独立 setInterval

**决策**：在现有 `tick()` 函数中新增秒级 accumulator，累积到 1000ms 时递减 `timeRemaining`。

**理由**：与游戏 tick 解耦但同帧更新，避免独立定时器漂移；暂停逻辑自然统一。

### 3. 特殊物品概率生成

**决策**：每次 `spawnFood()` 时按概率决定类型：

| 物品 | 概率 | 效果 |
|------|------|------|
| 🍎 普通食物 | 80% | +10 分 +5s |
| 🍏 金苹果 | 12% | +20 分 +10s |
| ⚡ 闪电 | 5% | 速度减半 3s |
| 🛡️ 护盾 | 3% | 免死一次（反弹方向） |

**理由**：常规 > 稀有 > 非常稀有的梯度让物品出现有新鲜感；护盾最稀有因为效果最强。

### 4. 护盾触发：方向反弹

**决策**：护盾激活时撞墙/撞自己 → 方向反转（`direction = { x: -direction.x, y: -direction.y }`），护盾消耗。

**理由**：反弹直觉自然，不需要额外边界处理；玩家立即感知护盾消耗。

### 5. 模式选择 UI：开始覆盖层内嵌卡片

**决策**：在 `#startOverlay` 中增加两张横向排列的模式卡片（经典 / 计时），默认选中"经典"。移动端竖向排列。

**理由**：用户在开始前自然看到选择，不增加额外步骤；默认经典保持向后兼容。

### 6. 计时器 UI 颜色状态

**决策**：Header 新增"剩余时间"卡片，颜色按阈值变化：
- \>30s：`var(--accent)` 绿色
- 10–30s：`#fbbf24` 黄色
- <10s：`var(--danger)` 红色 + CSS 脉冲动画

**理由**：视觉分级让玩家无需读数字即可感知紧迫程度。

## Risks / Trade-offs

| 风险 | 缓解 |
|------|------|
| 单文件持续膨胀（预计 +400 行） | 保持清晰注释分区；后续可考虑拆分 |
| 特殊物品在高速时难以识别 | 每种物品有独特形状和光晕，非仅颜色区分 |
| 闪电 + 护盾同时激活状态复杂 | 闪电只影响速度、护盾只影响碰撞，正交设计 |
| 移动端计时器卡片显示空间不足 | Header 3 卡片用 flex wrap 或缩小字号适配 |

## Migration Plan

1. 不需要数据迁移：新增 `snake-best-score-timed` 键，经典模式继续读 `snake-best-score`
2. 部署：替换 `index.html` 即可，无构建步骤
3. 回滚：替换为旧版 `index.html`，多余 localStorage 键不影响功能
