## Why

当前游戏仅记录单一"最高分"数字，无法保存历史成绩记录。玩家每次破纪录后旧分数即消失，缺乏竞技感和成就追踪的乐趣。需要引入排行榜系统来记录多条历史成绩，支持昵称标识和按模式筛选，为玩家提供持续挑战自我的动力。

## What Changes

- 新增排行榜数据存储模块，使用 localStorage 保存最近 20 条历史成绩记录
- 每条记录包含：分数、日期、游戏模式、玩家昵称、蛇身长度、终局原因、所用皮肤
- 新增昵称设置功能，玩家可自定义昵称（默认"玩家"），修改后自动同步到所有历史记录
- 首次加载时自动将旧版 `snake-best-score-*` 数据迁移为排行榜条目
- 在开始界面增加排行榜 Top 5 摘要展示
- 新增独立的完整排行榜面板（全屏覆盖层），支持按模式筛选（全部/经典/计时）
- 游戏结束时显示当前成绩在排行榜中的排名
- 新增排行榜面板中的昵称修改和清空排行榜功能（清空需二次确认）

## Impact

- **代码变更**: 仅 `index.html` 单文件，新增约 150-200 行 JS 代码和约 80-120 行 HTML/CSS
- **存储变更**: 新增 `snake-leaderboard` 和 `snake-player-name` 两个 localStorage key，首次加载时读取并迁移旧的 `snake-best-score-classic` / `snake-best-score-timed` 数据
- **UI 变更**: 开始界面新增排行榜摘要区域和昵称输入；新增排行榜全屏覆盖层；游戏结束覆盖层新增排名提示
- **浏览器兼容**: 依赖 localStorage API（所有现代浏览器均支持），与现有项目兼容性要求一致
