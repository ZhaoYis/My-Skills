# 知识库健康报告模板

## 1. 总体状态

- 数据来源：`doctor --json` / 降级模式（二选一，必标）
- 总体状态：ok / warn / fail
- 健康评分：<0–100，若 doctor 提供>
- 趋势：<相比上次得分的变化，若使用 --history>

|------|------|---------|---------|

| 老化 |      |         |         |
| 索引 |      |         |         |

> 仅列出 warn / fail 的维度；ok 的维度可一句话带过。
