# 验证目标清单模板

逐条整理本次变更要验证的目标。可直接从 `opsx-design` 的"验证断言字段"转写。

| 编号 | 验证目标（断言字段） | 维度（接口/数据/影响面） | 数据来源 | 判定方式（自动/人工） | 预期结果 |
|------|---------------------|-------------------------|---------|----------------------|---------|
|      |                     |                         |         |                      |         |

## 填写规则

- **验证目标**：来自设计的断言字段，具体可判定（如"接口 X 返回字段 Y 为非空且类型为整数"）。
- **数据来源**：从哪里取真实样例（真实数据源 / 真实请求 / 已有用例），不编造数据。
- **判定方式**：纯查询/简单入参 → 自动；写操作/复杂对象/状态流转 → 人工。
- **预期结果**：通过的判定基准，供 `pass-criteria.md` 比对。
