# Phase 1：采集原型输入

## 目标

拿到可分析的原型素材，并确定本次走"外部工具"路径还是"降级描述"路径。

## 执行步骤

1. **识别输入类型**
   - 原型 / 设计稿链接
   - 界面截图（用户粘贴）
   - 对界面与交互的口头描述

2. **探测外部能力（可选，不强制）**
   - 若环境已安装浏览器自动化能力：可用于打开链接、截取页面。
   - 若环境已安装视觉 / OCR 分析能力：可用于从截图中识别文本、控件与布局。
   - 探测仅用于决定是否能自动采集；**不内置任何凭据 / 平台 / API Key**，所需访问信息由用户提供。

3. **选择路径**
   - **外部工具可用**：用其打开链接 / 解析截图，得到页面结构与文案。
   - **外部工具不可用（默认降级）**：请用户粘贴截图或口述界面与交互；基于用户提供的素材继续，不报错、不阻塞。

4. **记录采集方式**
   - 在输出中明确：本次是"外部工具采集"还是"降级描述"，便于评估结构化结果的可信度。

## 输出要求

- 一份原型素材清单（链接 / 截图 / 描述）。
- 明确标注采集路径（外部工具 / 降级）。

## Guardrails

- 不内置任何平台凭据；访问受限链接时请用户提供素材。
- 外部工具缺失不是失败；直接走降级路径。
- 不臆造素材中不存在的界面或功能。
