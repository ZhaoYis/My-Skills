# 写入位置约定

`opsx-learn` 默认采用“通用知识库”模式，不预设唯一目录。

## 优先级顺序

1. **项目已有知识目录**
   - 如 `.knowledge/`、`docs/knowledge/`、`knowledge/`、`docs/domain/` 等
2. **项目已有文档体系中的合适位置**
   - 如架构文档、API 文档、模块说明、FAQ、运行手册
3. **与用户确认后新建目录**
   - 常见候选：`.knowledge/`、`docs/knowledge/`

## 选择原则

- 优先复用现有信息架构，不额外制造第二套知识体系。
- 若知识属于长期维护资产，优先放在文档目录而非临时笔记目录。
- 若项目明显已经约定了知识库存放方式，直接遵循，不重复确认显而易见的选择。
- 若无法判断，必须向用户确认后再写入。

## 推荐分类

- 功能闭环 / 业务流程
- API / 接口契约
- 数据模型 / 存储约束
- 外部依赖 / 集成点
- 排障经验 / 常见坑
- 术语表 / 索引
