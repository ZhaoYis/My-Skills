# 知识条目模板

以下模板用于把候选知识整理成统一格式。可以按项目实际情况裁剪。

## 模板：功能闭环

```md
# <功能名称>

## 目标
- 这条能力解决什么问题

## 主流程
1. ...
2. ...
3. ...

## 关键规则
- ...

## 关键来源
- `path/to/file:line`
- `path/to/other-file:line`
```

## 模板：API / 接口契约

```md
# <接口或命令名称>

## 入口
- 路径 / 方法 / 调用方式

## 输入
- ...

## 输出
- ...

## 关键处理逻辑
- ...

## 关键来源
- `path/to/file:line`
```

## 模板：业务规则

```md
# <规则名称>

## 规则内容
- ...

## 触发条件
- ...

## 例外 / 风险
- ...

## 关键来源
- `path/to/file:line`
```

## 模板：外部依赖 / 集成点

```md
# <依赖或集成点>

## 作用
- ...

## 调用位置
- ...

## 关键约束
- ...

## 失败表现
- ...

## 关键来源
- `path/to/file:line`
```
