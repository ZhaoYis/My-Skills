# 知识条目模板

以下模板用于把候选知识整理成统一格式。可以按项目实际情况裁剪，优先保留可长期复用的解释、边界与来源，不直接大段复制源码。

## 使用原则

- 一条知识优先表达一个核心认知。
- 每条知识尽量都能回答：这是什么、为什么重要、何时生效、去哪里追溯。
- 若内容仍有不确定性，显式标记“待确认”。
- 若该知识更适合补充到已有条目，而不是新建文档，应优先标记为“补充已有条目”。
- 若该知识会引入新的 API 路径、功能域、数据模型、外部服务、风险主题或运维主题，应同步给出 `.knowledge/INDEX.md` 的建议更新项。
