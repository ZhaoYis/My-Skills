# 去重与合并规则

在沉淀知识前，先检查目标位置是否已有同主题内容。

## 判重信号

满足任一情况时，优先视为“可能重复”：
- 标题或主题高度相同
- 指向相同接口 / 模块 / 业务流程
- 描述的是同一条业务规则
- 引用的是同一组关键代码来源

## 处理策略

1. **完全重复**
   - 不新增，直接跳过，并向用户说明原因。
2. **已有条目更完整**
   - 不新建，仅补充缺失来源或备注。
3. **新条目补充了新事实**
   - 合并到旧条目中，并明确新增部分。
4. **主题相同但视角不同**
   - 仅在确有长期价值时拆成子条目，并建立互相引用。

## 禁止项

- 不要为了“凑数量”重复写多个高度相似的条目。
- 不要覆盖用户手工维护内容，除非用户明确要求。
- 不要把未确认的猜测合并进已有稳定知识。
