# Phase 2：定位入口与上下文

## 目标

找到本轮学习对象在仓库中的真实入口，并建立初始上下文。

## 执行步骤

1. 根据学习入口，在代码、文档、配置、测试中寻找最直接的落点。
2. 记录入口相关的关键文件，例如：
   - 路由 / handler / controller
   - service / use case / manager
   - schema / DTO / model
   - 设计文档 / README / ADR / 知识文档
3. 判断入口是否已经足够代表该功能闭环。
4. 若存在多个候选入口，列出差异并请用户确认采用哪一个。

## 输出要求

至少给出：
- 当前确认的主入口
- 关联的关键文件或文档
- 为什么这些入口与本轮目标相关
- 下一步准备追踪的方向

## Guardrails

- 入口定位优先选择“最靠近用户问题”的位置，不要一开始就跳到过深的底层实现。
- 若仓库已有现成知识文档，必须先纳入上下文，避免重复劳动。
