# Phase 1：明确目标与边界

## 目标

把“想学什么、为什么学、这次覆盖到哪里”为后续追踪定清楚。

## 执行步骤

1. 识别用户输入属于哪一类：
   - API / 路径
   - 方法 / 类 / 模块
   - 功能描述
   - 文档 / 需求片段
   - 业务域 / 问题域
2. 判断当前范围是否足够开始追踪。
3. 若范围过大，主动收缩为一个可执行的学习单元，例如：
   - 一个接口
   - 一个功能闭环
   - 一个模块中的一条关键链路
4. 与用户确认本轮只处理一个清晰目标。

## 输出要求

至少给出：
- 本轮学习目标
- 学习入口
- 暂定边界
- 明确的不确定项
- 下一步准备定位的入口

## Guardrails

- 不要在范围未确认前直接开始大面积搜索。
- 若用户表达的是“想整体了解系统”，先帮助其拆成首个最值得学习的子目标。
- 如果同一请求同时包含多个入口，优先让用户确认优先级。
