# 需求澄清问题清单模板

## 需求澄清问题清单

| 编号 | 关联功能 | 问题描述 | 优先级(P0阻塞/P1) | 关联位置 |
|------|---------|---------|------------------|---------|
|      |         |         |                  |         |

## 填写规则

- **问题描述**：必须具体可回答（"上限 50 万是否可配置？"而非"这功能怎么做？"）。
- **优先级**：`P0 阻塞`（不回答无法继续）/ `P1`（影响质量但可并行）。
- **关联位置**：对应需求 / PRD / 代码中的位置，方便对方定位。
- 不猜测答案；不替干系人做决策；同一不明确点不拆成多条。

## 示例

| 编号 | 关联功能 | 问题描述 | 优先级 | 关联位置 |
|------|---------|---------|--------|---------|
| 1 | 数据导出 | 导出上限 50 万条是否可配置？默认值是多少？ | P0 阻塞 | PRD 3.2 |
| 2 | 数据导出 | 超过上限时是截断、报错还是分批？ | P0 阻塞 | PRD 3.2 |
| 3 | 导出格式 | 导出字段的时间单位是秒还是毫秒？ | P1 | PRD 3.4 |
