# Phase 3：输出 / 可选分享

## 目标

把问题清单交付出去：默认在对话中呈现；若用户需要对外发送，则以平台无关的方式抽象处理。

## 执行步骤

1. **默认：对话内输出**
   - 直接在对话中给出完整问题清单（表格形式），P0 在前。
   - 这是默认且无任何外部依赖的交付方式。

2. **可选：对外分享**
   - 仅当用户明确要求"发给某人/某平台"时执行。
   - 抽象为"按目标平台的 webhook / 接口发送"，**不内置任何具体平台、凭据或接口地址**。
   - 所需的目标地址、凭据、消息格式由用户提供；本 skill 只负责把清单整理成适配发送的文本/结构。
   - 用户未提供发送通道时，回退到对话内输出，不报错。

3. **附带跟进建议（可选）**
   - 可提示：哪些是 P0 阻塞、建议优先回收答案；回答回收后可进入 `opsx-analysis` 或 `opsx-design`。

## 输出要求

- 一份可直接复制发送的问题清单。
- 若涉及对外发送，给出平台无关的发送说明，不暴露任何内置凭据。

## Guardrails

- 不内置任何 IM / 平台凭据或固定接口。
- 无外部凭据时必须能完整产出（对话内）。
- 不替用户决定发送对象或发送时机。
