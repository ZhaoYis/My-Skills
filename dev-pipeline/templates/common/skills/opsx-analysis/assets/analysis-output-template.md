# 默认分析输出模板

默认输出应优先以对话中的结构化结果呈现，可按下列顺序组织：

## 1. 需求摘要
- 这次要分析什么
- 当前输入来源

## 2. 范围界定
- In scope
- Out of scope

## 3. 功能点拆解
- 功能点 A
- 功能点 B
- 功能点 C

## 4. 影响面分析
- 接口 / 命令 / 入口
- 模块 / 流程 / 规则
- 配置 / 状态 / 数据
- 测试 / 文档 / 脚本
- 外部依赖 / 集成边界（如有）

## 5. 风险与待确认项
- 已知风险
- 关键信息缺口
- 需要用户补充确认的问题

## 6. 建议下一步
- 推荐的继续探索方向
- 推荐的决策点
- 是否需要进入实施或方案细化
