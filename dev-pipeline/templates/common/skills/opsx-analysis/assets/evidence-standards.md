# 证据标准

`opsx-analysis` 的分析结论必须尽量建立在可回溯证据之上。

## 优先证据来源

1. 已沉淀知识库
2. README / CLAUDE.md / AGENTS.md / docs/ / ADR
3. 代码入口与相关实现
4. 测试、配置、脚本
5. 用户补充说明

## 结论分级

- **已确认事实**
  - 可直接从知识、文档、代码、测试或配置中验证
- **基于证据的推断**
  - 有较强上下文支持，但仍不是显式定义
- **待确认问题**
  - 当前证据不足，必须由用户或更多上下文补足

## 输出要求

- 尽量说明结论依据来自哪里
- 不要把猜测写成既定事实
- 当知识与代码冲突时，明确标记差异
